Saves the original AAC audio without re-encoding. Fast and engine-free.

History shows the selected source audio. By default the app copies AAC when it is at least 112 kbps; otherwise it uses the best source, converting Opus to AAC 256k if needed.

Turbo fetches up to six byte ranges at once and is typically 3-4x faster on the default Invidious proxy; six connections are still subject to the server's bandwidth. It falls back automatically if ranges are rejected. On a phone, 240p or 360p is several times smaller than 720p/1080p. The first job also loads the ~32 MB FFmpeg engine once; later jobs reuse it. How this works

A browser cannot run yt-dlp, but public media can still be fetched when the source allows cross-origin requests. This app uses a CORS-enabled Invidious instance for YouTube: it downloads the video and audio streams in the browser and muxes them locally with FFmpeg.wasm. No local server is needed, even when this HTML file is opened directly from disk.

  1. YouTube / Shorts: no setup required.
  2. Direct .mp4 / .mp3 / image links: fetched directly.
  3. Instagram and other sites: start the local yt-dlp bridge in Settings, or use a Cobalt-compatible API with a key.

Browser download notes

  • The default Invidious instance is a public third-party service. If it is rate-limited or offline, change the instance in Settings.
  • Long or 4K videos require a lot of memory. 240p–720p is safest in a browser.
  • A CORS proxy can rescue direct media links, but extraction of Instagram or TikTok pages still needs a server or bridge.
  • Only download media you have permission to use.

Local yt-dlp bridge (for Instagram, TikTok, and friends)

          
Browsers cannot run yt-dlp. Save the script below as bridge.py, install yt-dlp, and run python bridge.py. The app can then fetch pages through it. YouTube does not need the bridge; it is handled directly. Some other sites may also need ffmpeg installed for yt-dlp to merge streams.
